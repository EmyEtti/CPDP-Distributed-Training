# Paper Results

This directory contains the numerical results reported in the FGCS paper
**“Controlled Periodic Synchronization for Efficient Data-Parallel Training.”**

The CSV files correspond to the tables reported in the manuscript and are used
by the plotting scripts to reproduce the associated figures.

The reported result files are kept separate from newly generated experiment
outputs. New runs are written under `results/new_runs/` and do not overwrite
the values reported in the paper.
